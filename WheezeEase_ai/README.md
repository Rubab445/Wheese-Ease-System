# WheezeEase AI Module

AI-powered asthma and allergy risk prediction system developed by Rubab Rafeeq for Final Year Project.

## Project Overview

WheezeEase uses machine learning to predict asthma/allergy risk levels (Low/Medium/High) by analyzing:
- Patient profile (age, medical history, allergies)
- Symptoms frequency
- Medication usage
- Real-time environmental data (AQI, pollen, temperature, humidity)

## Features

✅ Multiple ML models (Logistic Regression, Random Forest, Neural Network)  
✅ Real-time environmental data from OpenWeather API  
✅ REST API for easy integration  
✅ Personalized risk predictions and recommendations  
✅ Comprehensive model evaluation and documentation
